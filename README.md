# Birthday Scrapbook Website

A responsive birthday-surprise website recreated from the reference video: deep red editorial landing screen, envelope/camera/bouquet hero, click-to-open transition, scrapbook pages, film strip and handwritten-style memory letter.

## Run it

No build step is required.

1. Extract the ZIP.
2. Open `index.html` in Chrome/Edge/Firefox.
3. For local development, you can also run `python -m http.server 8000` in this folder and open `http://localhost:8000`.

## Customize

- Edit the birthday text in `index.html`.
- Change colors, spacing and typography in `styles.css`.
- Replace the gradient `.photo-one` and `.photo-two` blocks with `<img>` tags if you want real photos.
- Edit the interaction in `script.js`.

## Note

The reference video does not contain the original website source/assets, so this is a functional visual recreation based on the visible design and interaction rather than a byte-for-byte copy of the original site.
